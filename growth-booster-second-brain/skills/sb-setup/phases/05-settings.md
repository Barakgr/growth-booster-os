# Phase 5 — Settings and plugins (10 minutes)

## Goal
Four Obsidian settings changed so new notes land in the inbox, and up to three optional add-ons installed by the owner.

## Reads first
- `reference/obsidian-guide.md`, sections "Settings to change", "Plugins", and "Optional: the Obsidian skill pack for Claude"

## Steps

1. **Settings.** In an **as-is** vault, ask first: "Four small settings help new notes land in the right place. Your current setup may already have its own. Change them? (**go** / **skip**)". Otherwise just proceed. Walk through "Settings to change" one setting at a time, waiting for **done** after each. For `on-top`, the inbox and attachments folders are inside the area folder (e.g. `Business/inbox`).

2. **Plugins.** Say:
   > "Three optional add-ons make Obsidian nicer. None is required. I'll describe each in one line; say **install** or **skip**."

   Present them one at a time from "Plugins" in the reference file, with the one-line reason. If the owner says install, walk through the install steps, waiting for **done**. Record which ones they installed in the phase log line.

3. **Skill pack.** Mention the optional Obsidian skill pack for Claude in one line, from the reference file. Only offer it. The owner adds it through Customize → Plugins; Claude doesn't.

4. If the owner asks for more plugins, tell them to live with these for a few weeks first. Most people never need more.

5. Mark Phase 5 complete. Use the standard end line.
