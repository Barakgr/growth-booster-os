# Phase 2 — Install Obsidian (5 minutes)

Skip this phase (mark `skipped`, reason "already uses Obsidian") when Phase 1 found an existing vault.

## Goal
Obsidian installed on the owner's computer. Opening the vault happens in Phase 4, after Phase 3 builds the folders.

## Reads first
- `reference/obsidian-guide.md`, section "Install Obsidian"

## Steps

1. Say:
   > "Obsidian is a free app for reading and writing notes, business use included. No account needed. You'll install it; I never install anything on your computer."

2. Walk through "Install Obsidian" in the reference file one step at a time. Wait for **done** after each.

3. If the owner gets stuck, ask them to describe what's on the screen and adapt. Button names shift between Obsidian versions.

4. Tell them to leave Obsidian on its welcome screen for now:
   > "Leave it on the welcome screen. I'll build your folders next, then we'll open them in Obsidian together."

5. Mark Phase 2 complete. Use the standard end line.
